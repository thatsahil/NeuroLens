# Machine Learning Pipeline & Training Workflow

This directory contains ML evaluation scripts, training notebooks, and future Federated Learning (FL) simulation hooks.

## Directory Structure
- `notebooks/` - Jupyter notebooks for exploratory data analysis & benchmark experiments
- `training/` - Training scripts for DenseNet121, ResNet50, and EfficientNet-B0
- `evaluation/` - Model evaluation, confusion matrix generation, and F1 metrics

## Future Federated Learning (FL) Phase
Future iterations will introduce Flower + PyTorch + FedAvg to simulate decentralized multi-hospital collaborative training without raw data sharing.
